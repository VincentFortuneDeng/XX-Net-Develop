证据边界

页面只展示已采集事实，不把离线测试、无界面服务或页面打开请求扩大为完整桌面验收。

本页能够证明

  • 当前浏览器窗口内收到的脱敏运行快照；
  • 导入文件与当前进程代际一致时的固定探针结果；
  • 同段样本的计数变化、采集失败和资源瞬时值。

仍需独立验收

  • E1 无界面服务不能替代真实默认入口 E2；
  • 托盘菜单、用户实际看见页面和正常退出属于 E3；
  • 无样本、采集 unknown、窗口不足或代际不符均不能判为通过。
