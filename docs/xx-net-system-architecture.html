XX-Net 5.16.7.1 系统架构

单 Python 进程 · 本地应用代理 · 智能分流 · 多前端可靠会话 · 控制流 / 数据流分离

接入与分流

  • • 8086 统一识别 SOCKS、HTTP、CONNECT
  • • 用户规则、历史缓存、名单与 IP 地区共同决策
  • • direct / socks / gae 形成候选列表并依次回退
  • • DNS、DoH、DoT 与 UDP 是独立辅助能力

X-Tunnel 可靠会话

  • • conn_id 映射本地 TCP 连接，SN 排序与确认
  • • transfer_no 跟踪 HTTPS 往返及超时重试
  • • 多 roundtrip worker 共享 ProxySession
  • • 多 front 只负责传输适配，最终进入会话服务

边界与当前状态

  • • 单进程多线程模块，不是微服务集群
  • • 8085 是管理面，不是业务代理端口
  • • GAE 代码保留但当前禁用；1080 不支持 UDP
  • • front TLS 与可选应用层加密是不同层次
